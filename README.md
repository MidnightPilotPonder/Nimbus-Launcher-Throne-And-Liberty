**Supported OS:** Windows 10 / Windows 11 (only)

---

## 🎮 Что это?

Nimbus‑Launcher‑Throne‑And‑Liberty – это лёгкий, но мощный лаунчер для Windows, созданный специально для геймеров, которые хотят быстро управлять своей библиотекой игр, переключаться между кастомными профилями и запускать любимые проекты в один клик.

- **Мгновенный доступ** к установленным играм
- **Персонализированные профили** (графика, звук, скрипты)
- **Минималистичный UI**, который не нагружает систему
- **Полностью открытый код** – вносите свои улучшения!

---

## ✨ Ключевые возможности

| Функция | Описание |
|--------|----------|
| **Быстрый поиск** | Поиск по названию, тегам и метаданным в реальном времени. |
| **Кастомные профили** | Сохраняйте наборы параметров (разрешение, настройки DX, скрипты) и переключайте их за секунду. |
| **Коллекции** | Группируйте игры по жанрам, кампаниям или настроению. |
| **Однокнопочный запуск** | Запуск любой игры из любого профиля одним нажатием. |
| **Автосохранение состояния** | При закрытии лаунчера сохраняются последние выбранные профили и порядок игр. |
| **Тёмная/светлая тема** | Автоматическое переключение в зависимости от системных настроек. |
| **Поддержка Steam, Epic, GOG и локальных установок** | Автоматическое обнаружение путей и интеграция. |

## 🛠️ Сборка из исходников

> **Требования:** .NET 6 SDK, Visual Studio 2022 (или любой IDE, поддерживающая WPF).

```bash
git clone https://github.com/yourusername/Nimbus-Launcher-Throne-And-Liberty.git
cd Nimbus-Launcher-Throne-And-Liberty
dotnet restore
dotnet build -c Release
```

Полученный файл `NimbusLauncher.dll` можно разместить в любой папке и запустить через `dotnet` или собрать самостоятельный пакет с помощью `dotnet publish`.
